# **End-To-End Model [ete]** 

This repository contains the source code for the Full-Learning model associated to the paper "A Graph Attention Model for the Team Orienteering Problem", by Iván Peña-Arenas, Rym Nesrine Guibadj, Cyril Fonlupt and Sohaib Afifi. This paper has been presented at the 2nd International Symposium on Intelligent Technology for Future Transportation (ITFT 2025).

## **Test Environment**

This code has been tested on Ubuntu 18.04 using a single Nvidia RTX-3500 Ada with 12 GB of VRAM. The Hybrid graph attention model (HGAM) was implemented with Python, using the PyTorch and Numba libraries.
